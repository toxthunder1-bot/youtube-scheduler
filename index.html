YouTube Scheduler

YouTube Scheduler is a small personal tool. It runs on its owner's own computer and is used only with the owner's own YouTube channels. It is not offered to the public.

Each day it:

  • uploads short videos the owner made to the owner's channels, scheduled to publish at set times;
  • adds each video's title, description, tags, captions and thumbnail;
  • reads the owner's own channel statistics (views, watch time, likes, comments) so the owner can see what works.

It uses the YouTube Data API and the YouTube Analytics API, signed in with Google by the channel owner.
